**Fixed by plan-063 (Epic 3, `REQ-LAND-033`). Closing.**

L16's post-condition exempted the landing journal with a **substring** test against the raw
`git status --porcelain` line. Three things were wrong with it, and they compound:

1. **Substring, not prefix.** It exempted any path *containing* `.yf/plan/landing-journal`
   anywhere — and did not even reliably exempt the journal it was written for.
2. **The raw line, not the path.** A porcelain record carries a two-character status plus a
   space, and **quotes** paths containing spaces or non-ASCII bytes. A `startswith` over the raw
   line matches nothing; an `in` reinstates (1).
3. **No `-uall`.** Without it git **collapses** untracked directories to a single `?? .yf/`
   entry, which contains neither the journal path nor `land-beads.json`. No prefix filter can
   work over a collapsed entry — so the switch is a precondition of the filter, not a refinement.

Masked in this repository by the `/.yf/` gitignore anchor that `yf preflight` ensures, and
**inoperative in any repository without it**.

**The fix.** A single helper, `_dirty_outside_plan_dir`, reading
`git status --porcelain=v1 -uall -z`, splitting on NUL, and prefix-testing the **path field**
against a `.yf/plan/` allowlist. Rename and copy records (`R`/`C`) carry two NUL-terminated
fields and both are examined, because either being outside the plan folder is dirt.

**One rule, one implementation, two callers.** The same helper is L16's *enforcement* and the
dry run's *prediction* (`REQ-LAND-034`). Two independent implementations of one rule is precisely
how the dry run stops predicting L16 — the objective of the whole plan — so a second definition
site is a regression even when both copies agree today. A criterion pins the count at exactly one
(`grep -c 'def _[a-z_]*dirty_outside'`).

**Tests.** A sandbox repo built **without** the `/.yf/` anchor — the only configuration where the
filter is load-bearing at all — which first asserts that git's untracked-directory collapse is
actually reproduced before relying on it, then that the journal and `land-beads.json` are exempt
and a spaced path outside the plan folder is still caught. Plus a dedicated substring trap:
`docs/a.yf/plan/decoy.txt` *contains* the allowlist fragment but is not *prefixed* by it, and must
still be reported.
