## Resolution method — PRE-REGISTERED before the resolutions were produced

Operator decision: resolve pass-4's concerns by **delegating the edit proposals to a sub-agent**,
with the main session applying each one under an assert, then run pass 5 as a third independent
review. `max-review-cycles` raised 5 → 9 for this session to accommodate the methodology.

**Why:** the main session drafted this plan *and* resolved pass-3's concerns, and four of pass-4's
concerns (C21, C22, C26, C27) were introduced by that resolution round — a dropped guard clause, a
graph leaf, a fix recorded but never landed, and two fresh stale references created by the edit
that fixed eight stale references. **Measured injection rate: 4 defects across 11 resolutions ≈
36%.**

**The pre-registered test, written before the sub-agent returned anything.** After pass 5, count
the concerns attributable to *this* resolution round and divide by 17:

| Outcome | Reading |
| :-- | :-- |
| Injection rate **materially below 36%** | Delegated resolution is fruitful → file it upstream as a `SKILL.md` §3 change, alongside #184's dispatch fix |
| Injection rate **at or above 36%** | The delegation did not help; the defect source is elsewhere (plan size, or the main session's *application* step rather than its proposal step) → do not file, and say so |
| Pass 5 finds a **new class** neither round produced | Inconclusive on injection; report separately rather than folding into the rate |

**What the skill change would say if the evidence supports it** (drafted now so the claim cannot
drift to fit the result): §3's resolution step *may* delegate the **proposal** of edits to a
sub-agent, while the **main session applies and verifies them**. This preserves REQ-AGENT-043 —
which governs who *writes review artifacts*, not who *reasons about fixes* — and it is a genuine
amendment, because §3 currently states outright that *"the main session resolves the concerns and
re-runs the red-team itself."*

This pre-registration is itself research 004's **M11** pattern — a probe placed before the work
that depends on it, with a pre-registered risk and a written response — applied to a plan that
descoped M11 as a deliverable.
