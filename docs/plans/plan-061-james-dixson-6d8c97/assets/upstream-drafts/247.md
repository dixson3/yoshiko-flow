## The DRIFT-CHECK.md hit the issue did not count

`:219` and `:225` are §5 Required-Section Contracts naming `install.sh` as the required
Install-section source. **`:164` is a third**, in §3's `e-frontmatter` contract, which defined the
frontmatter keys as *"the frontmatter `install.py` actually reads"* — **an edge whose declared
source of truth is a file deleted at plan-010.** An edge whose authority does not exist can never
fail. It is repointed at `yf/src/frontmatter.rs`, which is what reads frontmatter today.

That is the error class §7's conflict policy exists to catch, committed inside the manifest.
`e-install-url` could never have caught it: it checks byte-identity of a URL duplicated between
`SKILL.md` and a README, **not that the mechanism named is real**.

The correct authority is now stated once: `yf harness skills install` and
`yf self install --from-build --build`, pinned as `REQ-YF-DOC-009`, and enforced by a gate over
the scoped instruction-surface path set.
